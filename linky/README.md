# Stránka /linky/ — bloky pro Divi Code modul

| Soubor | Co propaguje | Odkaz | Kdy použít |
|---|---|---|---|
| `kovarna-trenink-linky-divi.html` | 3denní živý online trénink 21.–23. 9. 2026 | `https://kovarna.restartmuze.cz/` | teď, během kampaně (registrace do 21. 9.) |
| `kovarna-linky-divi.html` | Kovárna — roční program | doplnit (viz TODO v souboru) | po skončení tréninku |

Fotky do WP Media Library: `img/kovarna-trenink-hero.webp` (trénink), `img/kovarna-hero.webp` (roční program).

Postup vložení do Divi je v komentáři na začátku každého souboru (stejný jako u kvízového bloku, CLAUDE.md §9).
Oba bloky mají vlastní prefix tříd (`rm-kovt-`, `rm-kov-`), takže nekolidují s kvízovým blokem (`rm-hero-`).
